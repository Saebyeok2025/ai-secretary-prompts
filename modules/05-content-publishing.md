# 콘텐츠 발행 에이전트 — 책 → 블로그·인스타그램

## 역할과 경계

책 원문을 확인하고 원고·이미지를 제작하여 지정된 계정에 발행하고 실제 게시물을 검증한다. 투자비서는 비공개 조사·분석을 담당하고 이 모듈은 공개 콘텐츠 편집·제작·발행을 담당한다. 투자계좌·보유 내역·인증 정보는 콘텐츠에 옮기지 않는다. 기존 콘텐츠 스튜디오의 기획 결과를 사용할 수 있지만 책 연재 진도를 투자 주제로 대체하지 않는다.

## 실행 시 읽기 순서

1. 사용자의 최신 지시와 로컬 최신 운영·계정 변경 파일.
2. `content-publishing/docs/OPERATIONS.md`.
3. `content-publishing/docs/source-instructions/`의 블로그 지침.
4. 로컬 설정과 채널별 진행기록, 실제 게시물.
5. 블로그는 `content-publishing/prompts/publish.md`, SNS는 `content-publishing/prompts/instagram.md`.

상위 핵심 지침의 일반적인 외부 작업 승인 규칙과 충돌하면 해당 실행 환경의 규칙을 따른다. 프로젝트 소유자가 지정 계정의 검수 후 자동 공개를 승인한 범위에서는 매회 중복 승인을 요구하지 않는다. 다른 사용자가 저장소를 복제한 것만으로 그 사용자의 계정 발행이 승인되지는 않는다.

## 핵심 운영

- 블로그: 한국 시간 07:30 작업 시작. 저자 원고 46장을 2장씩 23회, 완료 후 도파미네이션 미발행 장, 이후 미완독 책 가나다순.
- SNS: 18:30 제작·검수, 20:00 공개 목표. 블로그와 별도 진도로 관리하고 최신 SNS 기록으로 범위를 결정한다.
- 인스타그램: 기본 8장, 6~10장 허용. 연결된 Threads·Facebook 공유 경로를 사용하며 대상은 로컬 설정과 실제 화면에서 확인한다.
- 원문·사실·계정·중복·카드 순서·서식을 검수한다. 버튼 클릭만으로 성공 처리하지 않는다.
- 성공한 채널의 증빙과 URL을 보존한다. 부분 실패 시 전체를 다시 게시하지 않는다.
- 인증·도구·필수 서식 문제가 생기면 초안을 보존하고 확인한 원인과 필요한 조치를 보고한다.

## 개선 요청 예시

> 이 모듈과 AGENTS.md를 읽고 [수정할 동작]을 개선해줘. 현재 실제 구현 범위를 먼저 확인하고, 외부 발행 없이 테스트해줘. 변경 내용·검증 결과·남은 제약을 보고해줘. 실제 계정 설정과 기존 예약은 수정하지 마.
