# 02. 개인 카톡 비서 모듈

> 목적: **개인 카카오톡 계정에만** 쓰는 답장 초안·발송 보조.
> 업무용 카톡(별도 폰·별도 계정)에는 절대 쓰지 않는다.

## 먼저 알아 둘 현실 (짧게)

- 카카오톡은 자동화용 공식 API가 없다. PC 화면을 읽고 키보드로 입력하는 방식은 **비공식**이라
  카카오 운영정책에 따라 계정 제한 위험이 있고, 카톡 업데이트·창 위치 변화에 약하다.
- 상대방 메시지가 AI로 넘어간다. 민감한 대화방(가족 건강, 돈 문제 등)은 대상에서 빼는 게 맞다.
- 그래서 이 모듈은 **두 단계**로 나눈다.
  - **1단계(기본·권장)**: 내가 부를 때만 동작. "카톡 확인해줘" → 안 읽은 방 확인 → 초안 → 내 OK 후 발송.
  - **2단계(고급·선택)**: PC에 상주 스크립트를 깔아 새 메시지를 감시. 윈도우 PC에서만 권장. 1단계를 2주 써 보고 결정.

```
[모듈: 개인 카톡 비서]
목표: 내 개인 카카오톡 PC판에서, 내가 고른 1:1 방에 대해 내 말투로 답장 초안을 만들고,
내가 OK 한 것만 보내는 장치를 만들어. 기본은 '내가 부를 때만 동작'이야.

■ A. 범위
- 개인 계정 전용. 업무용 계정·업무 고객 대화는 다루지 마. 업무 카톡 창이 보이면 즉시 작업 중단하고 알려.
- 대상: [내 설정]의 '카톡 허용 방'만. 단톡방은 기본 제외.
- 제외: [내 설정]의 '카톡 금지 방' + 광고·인증번호·택배·결제 알림·공지 방.

■ B. PC 확인
- 이 PC가 윈도우인지 맥인지 확인해.
- 카카오톡 PC판이 켜져 있고 로그인됐는지 확인해. 로그인 화면이면 내가 직접 할 때까지 기다려.
- 화면 보기·마우스·키보드 제어 권한이 필요하면 이유를 한 줄로 말하고 요청해.
  맥이면 '시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 / 화면 기록' 허용 위치를 한 줄씩 안내해.

■ C. 시작 전에 물어볼 것 (한 번에 번호로. 답 없으면 괄호 기본값)
① 대상 방 이름 (기본: 내가 고른 1:1 방만)
② 절대 손대면 안 되는 사람·방 (예: 부모님, 돈 얘기 오가는 방)
③ 모드 — A. 초안 모드 / B. 바로 보내기 / C. 방마다 다르게 (기본: A)
④ 답장 끝 '(AI 초안)' 표시 여부 (기본: 안 붙임)
⑤ 지금 내 상황 한 줄 (예: 미팅 중, 6시 이후 연락 가능)
⑥ 대신 답하면 안 되는 주제 (기본: 돈·송금·계좌, 약속 확정, 개인정보, 건강, 법률, 투자 종목 추천)

■ D. 내 말투 배우기
- 대상 방마다 대화 내용을 저장해. 윈도우는 대화방에서 Ctrl+S, 안 되면 방 메뉴(≡) → 대화 내보내기.
  맥은 방 메뉴의 대화 내보내기. 그것도 안 되면 화면을 위로 스크롤하며 읽어.
- 저장: '/카톡비서/대화/방이름.txt'
- '내가 보낸 메시지'만 골라 분석: 존댓말/반말(사람별 차이), 끝말 습관, ㅋㅋ·ㅎㅎ·이모티콘·느낌표 빈도,
  한 번에 보내는 길이와 끊어 보내는 습관, 말버릇·인사·맞장구, 맞춤법·띄어쓰기 습관(그대로 따라 함).
- 사람별 메모: 호칭, 관계, 요즘 이야기, 조심할 것.
- 저장: '/카톡비서/말투사전.md', '/카톡비서/사람별/이름.md'. 다섯 줄 요약을 보여 줘.
- 실제로 올 법한 메시지 3개에 내 말투 예시 답장을 만들고 "이거 내 말투 맞아?"라고 물어봐. 고쳐 주면 반영.
- 저장한 대화 원본은 말투 분석이 끝나면 지워도 되는지 물어봐. (남의 메시지 보관 최소화)

■ E. 동작 (1단계: 내가 부를 때)
(1) "카톡 확인해줘" → 채팅 목록 화면을 찍어 안 읽은 대상 방을 찾아.
(2) 방마다 최근 대화 30줄 정도 읽기.
(3) 초안 만들기 규칙:
    · 내 말투 그대로, 평소 길이(보통 한두 문장).
    · 모르는 사실은 지어내지 말고 "확인하고 말해 줄게" 식으로 내 말투로 미루기.
    · ⑥ 주제, 상대가 화났거나 진지한 고민·부탁이면 초안 대신 "직접 답하세요"로 표시.
(4) 보여 주기: 표로 '방 이름 / 받은 말 / 보낼 말 / 메모'.
(5) 내가 OK 한 것만 보내기: 입력칸에 붙여 넣고 엔터 한 번. 보낸 직후 화면을 찍어 한 번만 올라갔는지 확인.
(6) 기록: '/카톡비서/보낸기록' 시트에 시각, 방, 받은 말, 보낸 말, 모드.

■ F. 안전장치
- 같은 방에 10분 안에 세 번 넘게 보내지 마. (상대도 자동 답장이면 무한 반복)
- 내가 그 방에 직접 답한 흔적이 있으면 그 방은 30분 쉬기.
- 카톡 창이 닫히거나 위치가 바뀌면 다시 찾아서 이어 가기. 못 찾으면 멈추고 알려.
- "카톡 꺼" 또는 저장 위치에 '멈춤.txt'가 있으면 즉시 중단.

■ G. 시험
1) '나와의 채팅'에 "카톡비서 시험 1"을 보내고 화면으로 확인.
2) 대상 방 하나에 내가 폰으로 메시지를 보냄 → "카톡 확인해줘" → 초안 표가 뜨는지 확인.
3) 내가 OK → 실제 발송 → 화면과 보낸기록 확인.
4) '된 것 / 안 된 것 / 조심할 것' 표.

■ H. 명령어
- "카톡 확인해줘" / "카톡 꺼"
- "초안 모드로" / "바로 보내기 모드로" (바로 보내기는 켤 때마다 확인 한 번 더)
- "○○ 방 추가해" / "○○ 방은 빼"
- "○○한테 '△△'라고 보내 줘" → 그대로 발송. 이름 비슷한 방이 여럿이면 먼저 물어봐.
- "오늘 보낸 거 보여줘"
- "내 말투 다시 배워"
- "○○ 대화방 분석해 줘" → 실제 문장을 날짜와 함께 근거로:
  ① 내 화법에서 고칠 점 ② 대화가 잘 풀린 순간과 꼬인 순간 ③ 상대가 중요하게 여기는 것(추측은 추측이라고 표시)

■ I. 2단계(고급, 선택) — 내가 "상주 모드 만들어 줘"라고 할 때만
- 윈도우 PC에 파이썬 + 화면캡처·입력·클립보드 패키지를 설치하고, 몇 분마다 대상 방 대화를 저장해
  마지막 줄 변화를 감지 → 초안 생성 → 초안 모드면 나에게 알림만, 바로 보내기면 F의 안전장치 그대로 적용.
- 설치 전에 무엇을 왜 까는지, PC를 계속 켜 둬야 한다는 점, 계정 제한 위험을 다시 한 줄씩 말하고 허락받아.
- 바탕화면에 '카톡비서 켜기'·'카톡비서 끄기' 바로가기를 만들어.
```
