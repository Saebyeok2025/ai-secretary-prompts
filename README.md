# AI 비서 프롬프트 키트 (Claude용)

Claude(특히 Cowork·프로젝트 기능)에서 **개인 AI 비서**를 세팅하기 위한 프롬프트 모음입니다.
코딩을 몰라도 복사 → 붙여넣기만으로 쓸 수 있게 만들었습니다.

- 공통 **코어**(일하는 방식·안전 원칙·이어가기 규칙) 1개
- 필요한 것만 골라 붙이는 **모듈** 4개
- 내 정보만 채우면 되는 **설정 템플릿** 1개

## 구성

| 파일 | 내용 | 언제 쓰나 |
|---|---|---|
| `00_core.md` | 일하는 방식, 절대 금지, 저장 위치, 공통 명령어, 마무리 보고 형식 | **항상** |
| `modules/01_investment-secretary.md` | 매일 아침 확률 시나리오 브리핑, 테제 점검, 매매 복기 | 투자 관리 |
| `modules/02_kakao-personal.md` | 개인 카톡 말투 학습, 답장 초안, OK 후 발송 | 개인 카톡 정리 |
| `modules/03_content-studio.md` | 소재 → 대본 → 블로그 → 쇼츠 → 발행 체크리스트 | 유튜브·블로그 |
| `modules/04_book-lecture.md` | 원고 관리·퇴고, 강의안, 무료특강→유료과정 일정 | 책·강의 |
| `config/my-config.example.md` | 내 설정 빈칸 템플릿 | 처음 한 번 |

## 쓰는 법 (3단계)

1. `config/my-config.example.md`를 복사해 `my-config.md`로 저장하고 빈칸을 채웁니다.
2. Claude에서 새 프로젝트(예: "AI비서")를 만들고, 프로젝트 지침에
   **`00_core.md` + 쓰려는 모듈 + `my-config.md`** 내용을 붙여 넣습니다.
   (프로젝트 기능이 없으면 새 대화 첫 메시지로 붙여 넣어도 됩니다.)
3. "1번부터 시작해 줘"라고 말합니다. 비서가 환경 확인 → 질문 → 학습 → 구축 → 시험 순서로 진행합니다.

다음부터는 새 대화에서 **"AI비서 README 읽고 이어서 해"** 한 줄이면 이어집니다.

## 추천 시작 순서

처음부터 모듈 네 개를 다 켜지 마세요. 유지가 안 됩니다.

1. **1~2주차**: 코어 + 투자비서(일일 브리핑만)
2. **3주차~**: 브리핑을 실제로 읽고 있다면 콘텐츠 스튜디오 추가
3. 필요할 때: 책·강의, 개인 카톡 비서

## 설계 원칙

- **증거로 확인**: "됐을 거예요" 금지. 화면·메일·시트 기록으로 확인합니다.
- **지어내지 않기**: 모르는 숫자·약속은 "확인 불가"로 표시합니다.
- **민감정보 금지**: 비밀번호·인증번호·계좌·카드·API 키는 묻지도 입력하지도 않습니다.
- **투자는 신호가 아니라 확률**: 매수·매도를 지시하지 않고 시나리오·확률·무효화 조건으로 답합니다.
- **개인 용도 전용**: 업무 계정과 업무 고객 정보는 다루지 않습니다.

## 주의

- **투자**: 이 키트의 출력은 개인 참고용이며 투자 권유가 아닙니다. 남에게 개별 종목 매수·매도 의견을 주는 건
  법적으로 투자자문 영역일 수 있으니, 공개·유료로 쓰기 전에 관련 규정을 확인하세요.
- **카카오톡**: 공식 자동화 API가 없어서 화면 자동화는 비공식 방식입니다. 계정 제한 위험이 있고,
  상대방 메시지가 AI로 전달됩니다. 기본값인 '초안 모드 + 내가 부를 때만'을 권장합니다.
- `config/my-config.md`(개인 설정)는 `.gitignore`에 들어 있어 이 저장소에 올라가지 않습니다.
