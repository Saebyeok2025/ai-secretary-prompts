# SNS 카드뉴스 제작·공개 실행 프롬프트

AGENTS.md, docs/OPERATIONS.md, 로컬 최신 계정·운영 변경 파일을 먼저 읽어라. 아래 대상은 보조 코드가 계산한 제안이다. 최신 SNS 진행기록과 실제 게시물로 확정하라. 블로그 진도와 섞지 마라. 기록이 충돌하면 공개를 멈추고 초안과 확인 사항을 보존하라.

1. 원문에서 두 장 묶음 또는 해당 책의 큰 장 시작·끝을 확인하고 읽어라. 출처·사실·직접 인용을 검수하라.
2. 로컬 참고 이미지·영상 중 주제에 맞는 형식을 골라 이유를 기록하라. 6~10장(기본 8장)의 카드 문구·캡션·대체텍스트를 작성하라.
3. 이미지 생성 도구로 카드 이미지를 제작하라. 같은 1080×1350 비율, 한 카드 한 메시지, 읽기 쉬운 한글과 충분한 여백을 사용하라. 모든 카드의 오탈자·잘림·순서·내용을 검수하라.
4. 원고·이미지·캡션·대체텍스트·제작 기록을 로컬에 저장하라. 캡션은 출처·AI 생성 고지·해시태그 포함 500자 이내로 하라.
5. 실제 로그인 Instagram 계정, 연결 Threads 계정, Facebook 개인 프로필을 로컬 설정과 대조하라. 이번 게시물의 연결 공유 ON과 공개 범위를 확인하라. 대상 불일치 또는 연결 공유 불가 시 공개 전에 중단하라.
6. 20:00 Asia/Seoul 공개를 목표로 사전 제작·검수하라. 실제 예약 기능이 있을 때만 예약하고 시간과 공유 상태를 확인하라. 이 프롬프트를 읽은 것만으로 예약이 활성화됐다고 보고하지 마라.
7. 승인된 Instagram 업로드 → 연결 공유 경로로 공개하라. 별도 직접 게시로 전환하거나 계정 전체 공유 설정을 변경하지 마라. 녹화를 원하면 보이는 브라우저에서 작업하라.
8. 실제 세 서비스 게시물의 작성자·카드 수/순서·캡션·공개 범위·URL을 각각 확인하라. 부분 성공은 구분해 기록하고 전체를 다시 게시하지 마라. 완전 성공한 범위만 SNS 완료 진도로 갱신하라. 부분 성공은 서비스별 복구 대상으로 보존하고 재실행 전에 반드시 대조하라.
9. 성공이면 책·범위·카드 수·서비스별 링크·다음 범위를 보고하라. 중단이면 완료 파일·중단 지점·저장 위치·필요한 사용자 조치를 보고하라. 인증·도구 제한을 우회하지 마라.

현재 Python 명령은 계획과 이 프롬프트를 출력할 뿐 발행을 실행하지 않는다. 실제 도구가 있는 에이전트가 위 단계를 수행해야 한다.
