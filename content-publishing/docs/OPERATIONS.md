# 공통 운영 기준

이 파일은 2026-11-11 로컬 운영 파일을 정리한 배포용 기준이다. 계정·실제 진도·PC 경로는 제외했다. 운영 PC의 최신 변경 파일이 있으면 사용자 지시와 대조해 우선 적용한다. 예제 상태를 실제 진도로 사용하지 않는다.

## 원문과 책 선택

우선 원본은 `가상화폐이야기_첫출간/하룻밤에읽는가상화폐이야기_재교2.pdf`이다. 파일명과 다른 실제 표제는 『하룻밤에 읽는 가상화폐의 미래』, 저자는 새벽이다. 원문의 번호 있는 1~46장을 1·2, 3·4, …, 45·46으로 묶는다. 소주제·PDF 파일·페이지를 장으로 취급하지 않는다. 표지 PDF는 본문 원본이 아니다.

완료 후 도파미네이션의 미발행 큰 장부터 이어가고, 이후 미완독 책을 파일명 가나다순으로 처리한다. 합본·분할본·중복본은 같은 책으로 묶고 합본을 우선한다. 일반 책은 하루 큰 장 하나다. 책 목록과 장 수는 목차를 확인하여 설정에 등록한다. 현재 코드는 폴더에서 책의 장 수를 자동 판독하지 않는다.

진행기록과 실제 게시물을 대조하여 대상 범위를 결정한다. 기록 누락·과거 미발행 의심만으로 이미 선택된 연재 진도를 되돌리지 않는다. 순서 조정은 실제 게시 이력과 사용자 지시로 확정하고 기록한다. 블로그와 SNS 기록은 분리한다.

## 블로그

07:30 Asia/Seoul은 작업 시작 시간이다. 실제 발행 시각을 따로 기록한다.

구성: 썸네일 → 도입 → 목차 → 번호 있는 소주제 4~5개 → 결론 → 마무리 문장 → 출처. 목차와 실제 소제목을 일치시킨다. 각 소주제는 소제목 → 이미지 → 설명 순서다.

필수 썸네일을 먼저 생성한다. 기본 1254×1254, 굵은 한글 고딕 제목과 명조 계열 보조 문구. 로컬 참고 이미지에서 크기와 글자 스타일만 참고하고 주제에 따라 배경·소재·색을 바꾼다. 소주제 이미지 4~5장(기본 9:16)을 별도로 만들어 총 5~6장을 사용한다. 이미지 문구·사실·오탈자·잘림을 확인한다.

도입/목차/각 소주제/결론 사이 실제 편집기 구분선을 삽입하고 짧은 선을 가운데 정렬한다. 목차 제목은 24 굵게. 소제목·결론 소제목은 24 굵게 가운데. 본문은 본문 크기 왼쪽. 마무리는 ‘다시시작해’ 이탤릭. 출처 블록은 ‘바른히피’ 이탤릭. 해당 서식을 실제 게시물에서도 확인한다.

사용자 자신의 책은 저자가 이야기를 들려주는 시점으로 쓴다. 경제 지식이 없는 고등학생도 이해하도록 구체적 장면·질문·짧은 문단을 사용한다. ‘원고는/책에서는/저자는’ 같은 메타 해설을 반복하지 않는다. 타인의 책에서는 저자인 척하지 않는다. 특정 생존 작가의 문체를 복제하지 않는다. 없는 경험·사례·통계·인용을 만들지 않고 스캔의 손글씨 메모와 책 본문을 구분한다.

## 인스타그램과 연결 공유

SNS 독립 진행기록을 읽는다. 당일 블로그 범위·성공 여부로 SNS 범위를 임의 변경하지 않는다. 18:30 제작·검수, 20:00 공개 목표이며 예약 수단과 실행 준비가 확인되지 않으면 정각 공개를 보장하지 않는다.

기본 8장(6~10장), 같은 1080×1350 비율. 표지 → 공감 → 핵심 개념 → 원문 사례 → 이유 → 통찰/한계 → 생각할 질문 → 마무리·출처를 기본 흐름으로 삼는다. 한 카드 한 메시지, 큰 제목과 짧은 설명, 가장자리 충분한 여백을 사용한다.

로컬 `인스타그램_카드뉴스`의 이미지·영상에서 주제에 맞는 형식을 선택하고 선택 이유를 기록한다. 사진+큰 문장, 밝은 스토리 일러스트, 사진+인용문 등의 구성을 참고하되 로고·워터마크·다른 계정 문구를 복제하지 않는다. 영상 참고도 기본 결과물은 정지 이미지 캐러셀이다. 블로그 이미지를 그대로 재사용하는 대신 재구성한다.

캡션은 후킹·설명·한 가지 질문·책/장 출처·AI 이미지 안내·관련 해시태그를 합해 500자 이내로 작성하고 실제 게시창에서도 길이를 확인한다. 카드별 대체텍스트와 필요한 AI 표시를 적용한다.

계정명은 `sns.config.local.json`에서 읽고 실제 로그인·이번 게시물의 연결 공유 화면과 대조한다. Instagram에 캐러셀 1개 업로드 후 Threads와 Facebook 개인 프로필로 연결 공유한다. 페이지로 바꾸거나 각 서비스 별도 직접 게시로 자동 전환하지 않는다. 계정 전체의 항상 공유 설정은 변경하지 않는다.

공유 대상 불일치·공유 기능 부재 시 공개 전에 중단한다. 서비스별 실제 게시물과 URL을 확인한다. 일부만 성공하면 Instagram 전체 재업로드·실패 서비스 직접 게시를 하지 않는다. 기존 게시물의 연결 재공유 가능 여부와 중복을 확인하여 승인된 경로 안에서만 복구한다.

## 저장·중복 방지·검증

운영 PC의 제외된 output 또는 별도 자료 폴더에 날짜·책·범위별로 원고, 생성 프롬프트, 이미지, 캡션, 대체텍스트, 검수 결과, 게시 URL과 증빙을 저장한다. 진도는 실제 게시 확인 후에만 채널별로 갱신한다. 두 실행이 같은 채널을 동시에 조작하지 않도록 운영자가 실행을 직렬화한다. 현재 코드는 잠금·진도 자동 갱신을 구현하지 않는다.

PC 종료·절전·앱 미실행·연결 오류·인증·원문 판독·서식 문제를 구분하되 확인한 근거가 있을 때만 원인을 확정한다. 예약이 시작되지 않았으면 다음 재개 시 누락과 중복을 점검한다. 로그인·캡차·도구 제한은 우회하지 않는다.
