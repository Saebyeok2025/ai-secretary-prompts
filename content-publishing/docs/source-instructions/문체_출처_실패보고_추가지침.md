## 저자의 목소리

질문이나 낯선 장면으로 시작하고, 구체적 사건·사물·원문 숫자 → 독자의 궁금증 → 설명 → 다음 질문의 흐름을 만든다. 짧은 문단과 길이가 다른 문장, 자연스러운 자문과 독자에게 건네는 말을 사용한다. '이 장은 ~을 다룬다', '원고는 ~을 설명한다', '리뷰의 해석이다' 같은 보고서식 해설을 반복하지 않는다. 꼭 필요한 책·장 소개는 도입과 출처에 짧게 둔다. 제목에도 '리뷰'를 기계적으로 붙이지 않는다.

사용자가 2026-11-11 직접 수정한 3·4장 글의 리듬을 참고한다. 예: '돈을 받았는데, 손에 남은 것은 종이 한 장이다. 그 종이가 정말 금만큼 믿을 만할까.' / '5%가 작을 수 있지만, 1조라면?' / '하지만 은행, 금을 보관한 곳이 파산할 수 있다고 한다면?' 이는 호기심과 문체의 예시이며 다른 장에 내용·수치를 복제하지 않는다. 예시 속 수치나 역사 해석은 검증된 사실로 자동 채택하지 않는다. 새로운 경험·사례·통계·직접 인용은 만들지 않는다. 가정 계산은 가정임을 자연스럽게 밝힌다. 정확성을 지키되 본문에 편집자용 주의문이나 기계적인 면책 문장을 반복하지 않는다.
