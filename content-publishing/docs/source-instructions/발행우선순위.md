# 책 발행 우선순위 — 최신 변경 지침

1. 최우선 원본: ${SOURCE_ROOT}\가상화폐이야기_첫출간\하룻밤에읽는가상화폐이야기_재교2.pdf
2. 사용자가 직접 출판할 원고다. 표지 PDF가 아닌 재교2 본문을 읽는다. PDF는 129페이지이며 두 쪽 펼침이므로 인쇄 쪽수와 PDF 페이지를 구분한다.
3. 이 책에 한해 1~46장(사용자가 말한 소챕터)을 하루 2개씩 순서대로 묶어 블로그 글 1편으로 만든다. 1·2장, 3·4장, …, 45·46장으로 총 23회다. 부 단위나 장 내부 작은 소제목 2개를 뜻하지 않는다.
4. 첫 발행 대상은 1·2장이다. 기존 블로그에 유사 소재 글이 있어도 해당 묶음의 발행 여부를 확인한다. 이미 완료된 묶음은 중복 발행하지 않는다.
5. 두 장을 하나의 흐름으로 재구성하되 출처에 두 장의 제목과 범위를 모두 표시한다. 사용자 원고의 저자 시점을 유지할 때 사용자 경험과 원고 서술을 혼동해 새 경험을 만들지 않는다.
6. 46장까지 완료하면 도파미네이션의 미발행 장부터 재개한다. 1장은 발행 완료이므로 현재 재개 지점은 2장이다. 이후 최신 기록을 우선한다.
7. 도파미네이션 이후 미완독 책을 파일명 가나다순으로 진행한다. 일반 책은 기존대로 하루 큰 장 하나이며 이 책의 2장 묶음 예외를 확대하지 않는다.
8. SNS는 최신 변경에 따라 블로그와 독립 진도로 관리한다. 2장 묶음의 카드뉴스 6~10장, 18:30 제작·20:00 공개 목표를 적용하고 실제 예약 활성 여부는 운영 환경에서 확인한다.
9. 이 지침은 이전의 ‘도파미네이션부터’ 및 ‘모든 책 하루 한 장’ 설명보다 우선한다. 제목·필수 썸네일·본문 이미지·서식·검수·발행 규칙은 최신 통합 지침을 유지한다.
