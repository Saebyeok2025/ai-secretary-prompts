# 블로그 운영 요구사항

통합·SNS 최신 규칙은 OPERATIONS.md를 먼저 읽는다. 이 문서는 블로그 세부 기준이다.

## 범위와 진도

최우선은 사용자 출간 원고 재교2 1~46장, 하루 두 장씩 23묶음이다. 이후 도파미네이션 미발행 장부터 재개하고 미완독 책을 파일명 가나다순으로 진행한다. 일반 책은 하루 큰 장 하나다. 현재 게시 기록은 비공개 로컬 설정으로 이관하며 예제에 실제 완료 범위를 넣지 않는다.

사용자 정정으로 3·4장이 게시된 경우 1·2장의 완료 여부를 실제 게시물에서 확인한다. 확인되지 않은 장을 완료로 꾸미거나 planner가 반환한 과거 묶음을 무조건 재발행하지 않는다. plan은 설정과 상태를 계산할 뿐 현재 사이트의 진실을 알지 못한다.

## 콘텐츠·서식

사용자 자신의 책은 직접 들려주는 이야기체다. 타인의 책은 저자 시점을 사칭하지 않는다. 짧은 문장, 구체적 장면과 질문, 쉬운 용어 풀이를 사용한다. 원문과 사용자 수정 예시가 우선이며 특정 작가의 고유 문체 복제를 지시하지 않는다.

썸네일 1장(1254×1254px)을 도입 앞에, 소주제별 이미지 4~5장(기본 9:16)을 별도 배치한다. 참고 이미지의 굵은 고딕 제목·명조 보조문구를 참고하되 색·배경을 고정하지 않는다. 한글과 사실 오류를 검수한다.

목차 24 굵게, 소제목과 결론 24 굵게 가운데, 본문 왼쪽. 전환마다 실제 짧은 구분선 가운데. 마무리 다시시작해·이탤릭. 출처만 바른히피·이탤릭. 글꼴이 없으면 적용했다고 하지 않는다.

## 완료·장애

실제 게시물 URL, 공개 상태, 계정, 카테고리, 본문, 이미지 수·순서, 서식을 확인해야 성공이다. 시작·끝 시각과 실패 단계·확인된 원인을 로컬 로그에 남긴다. SNS 제작·공개 운영과 별도 진도 보조 코드는 이 패키지에 포함된다. 실제 발행 엔진은 포함하지 않는다.

## 구현 경계

현재 브라우저 발행은 Codex의 제공 도구가 담당한다. agent.py에는 네이버 로그인·이미지 생성·업로드·예약 엔진이 없다. Python CLI 자체를 실행해도 글이 게시되지 않는다. 별도 서비스로 확장하려면 공식 도구 지원과 인증·실행 환경을 먼저 검증하고 어댑터를 추가한다. 세션 쿠키를 저장소에 넣지 않는다.
