# Codex 작업 규칙

이 저장소는 로컬 Codex 기반 발행 워크플로의 지침과 보조 코드다. 실제 브라우저·이미지 도구는 해당 Codex 실행 환경에서 제공되어야 한다. 지원되지 않는 도구를 구현된 것처럼 표시하지 않는다.

코드 변경 전 README와 docs/requirements.md를 읽는다. 원고·책 PDF·브라우저 프로필·인증·로컬 설정은 커밋하지 않는다. 공개 게시를 테스트 수단으로 사용하지 않는다. 변경 후 `python -m unittest discover -s tests -v`를 실행한다.

원문에 없는 사실·인용·사용자 경험을 만들지 않는다. 사용자 소유 책은 저자의 이야기체, 타인의 책은 저자인 척하지 않는 요약으로 작성한다. 최종 게시 전 실제 범위·중복 여부·서식·이미지를 검증한다. 게시 성공은 실제 게시물 URL에서 확인한 후 기록한다.

새 책은 목차로 장 개수를 확인하고 설정에 명시한다. 우선 책 이후 책은 파일명 가나다순으로 정리하되 합본·분할본 중복을 제거한다. 자동 검색으로 추정한 장 수로 공개 발행하지 않는다.

## 블로그와 SNS 통합 모듈
먼저 docs/OPERATIONS.md를 읽는다. SNS는 sns.py와 prompts/instagram.md를 사용하며 블로그와 독립 상태를 유지한다. 계정 예제를 실제 대상으로 사용하지 않는다. 실제 게시 엔진·스케줄러가 구현됐다고 설명하지 않는다. 외부 게시 없는 테스트: python -m unittest discover -s tests -v.
